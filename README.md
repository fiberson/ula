# ЮЛА — печатный центр

Статическая адаптивная вёрстка главной страницы печатного центра ЮЛА. Проект подготовлен для совместной разработки и публикации через GitHub Pages.

## Текущее состояние

- главная свёрстана по PSD для desktop, tablet и mobile;
- фотографии оптимизированы в WebP, шрифты хранятся локально;
- мобильное меню, попап и клиентская валидация работают;
- `polygraphy.html`, `merch.html`, `useful.html` и `contacts.html` временно являются заглушками и закрыты от индексации;
- форма пока не отправляет данные на сервер — обработчик будет подключён при интеграции с WordPress или отдельным backend;
- ссылки MAX и VK пока ведут на главные страницы платформ до получения адресов профилей заказчика.

## Локальный запуск

Никакая сборка и установка зависимостей не нужны.

```bash
python3 -m http.server 4173
```

После запуска открыть `http://127.0.0.1:4173/`.

## Структура

```text
assets/
  css/style.css      — стили и адаптив
  fonts/             — локальные Manrope и Unbounded
  images/            — production-изображения и иконки
  js/main.js         — меню, попап и форма
index.html           — главная
*.html               — временные страницы разделов
robots.txt           — правила индексации
sitemap.xml          — карта боевого домена
```

PSD, QA-скриншоты, временные файлы, release-архивы и неиспользуемые тяжёлые PNG исключены через `.gitignore` и не должны попадать в публичный репозиторий.

## Работа вдвоём

Рекомендуемый порядок для Артемия и остальных участников:

1. Получить доступ к репозиторию и клонировать его.
2. Создать ветку от свежей `main`, например `artemiy/contacts-page`.
3. Внести изменения и проверить контрольные ширины из `CONTRIBUTING.md`.
4. Открыть pull request в `main` и приложить скриншоты визуальных изменений.
5. После merge GitHub Actions автоматически обновит GitHub Pages.

## Создание публичного репозитория

Из корня проекта:

```bash
gh repo create <имя-репозитория> --public --source=. --remote=origin --push
```

Затем на GitHub открыть **Settings → Pages** и выбрать **Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует сайт при каждом push в `main` и также запускается вручную.

Адрес project site будет иметь вид:

```text
https://<владелец>.github.io/<имя-репозитория>/
```

Все внутренние пути относительные, поэтому сайт работает как в корне домена, так и во вложенном пути GitHub Pages.

## Добавление Артемия

Нужен его точный GitHub username. После создания репозитория: **Settings → Collaborators → Add people**, найти username Артемия и отправить приглашение.

## Боевой домен

Canonical, Open Graph, `robots.txt` и `sitemap.xml` сейчас настроены на `https://ulaprint.ru/`. Файл `CNAME` намеренно не добавлен: подключать домен к GitHub Pages следует только после настройки DNS и согласования места боевого хостинга.

## Лицензия

Открытая лицензия не выбрана. Публичная видимость репозитория сама по себе не даёт разрешения на повторное использование клиентского дизайна и материалов.
