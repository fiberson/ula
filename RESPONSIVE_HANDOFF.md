# Передача адаптивной вёрстки «ЮЛА»

Дата фиксации: 9 сентября 2026 года.

Рабочая ветка: `codex/responsive-layout`.

Основа: `main`, коммит `5dc6748`.

## Что уже сделано

- Пересобран адаптив главной страницы без резких скачков между десктопом, планшетом и телефоном.
- Полное меню сохраняется на планшетах и компактных экранах до ширины 640 px; бургер появляется только ниже 640 px.
- Мобильное меню находится за правой границей страницы и открывается справа налево только после нажатия, поэтому при смене брейкпоинта нет стартового рывка.
- Исправлены переполнения и смещения в секциях «Хиты», «Каждый проект — отдельная история», «Готовы превратить идею в тираж», блоках услуг, процесса и описания компании.
- Главный коллаж, типографика, отступы и кнопки плавно масштабируются между контрольными ширинами.
- Убрана светлая полоса под главным коллажем.
- Социальные иконки MAX и VK переведены в SVG, чтобы они не пикселили.
- На планшете восстановлен блок процесса «От идеи до тиража — 4 шага».
- Добавлена поддержка экранов уже 360 px: макет сохраняет минимальную ширину и пропорционально уменьшается целиком, не разрывая контент.
- Добавлена обработка `prefers-reduced-motion` для пользователей с отключённой анимацией.

## Карта адаптива

- `0–359 px` — безопасное пропорциональное уменьшение мобильного холста шириной 360 px.
- `360–639 px` — мобильная компоновка и бургер-меню.
- `640–743 px` — компактная мобильная компоновка с обычными ссылками в шапке.
- `744–1199 px` — планшетная компоновка.
- `1200–1399 px` — плавный переход к десктопной композиции.
- `1400 px и шире` — полная десктопная композиция.

## Что проверить и продолжить

- Страницы «Полиграфия», «Фирменный мерч», «Полезное» и «Контакты» пока являются заглушками.
- Форма заявки имеет интерфейс и проверки, но ещё не подключена к серверу или CRM.
- Ссылки MAX и VK пока ведут на главные страницы платформ; перед публикацией нужны реальные адреса профилей заказчика.
- Перед переносом в CMS нужно сохранить текущую HTML-структуру и адаптивные правила, затем отдельно подключить динамический контент и обработчик формы.
- После наполнения внутренних страниц повторить проверку на реальных iOS/iPadOS/Android-устройствах и в актуальных Safari, Chrome и Firefox.

## Как продолжить на другом компьютере

```bash
git clone https://github.com/fiberson/ula.git
cd ula
git switch codex/responsive-layout
python3 -m http.server 4174
```

Открыть в браузере: `http://127.0.0.1:4174/index.html`.

Если репозиторий уже клонирован:

```bash
git fetch origin
git switch codex/responsive-layout
git pull --ff-only
```

## Проверки перед передачей

- JavaScript проверен командой `node --check assets/js/main.js`.
- SVG-иконки проверены как валидный XML.
- Все пять HTML-страниц проверены через локальный HTTP-сервер.
- Рабочие контрольные ширины: 320, 360, 390, 440, 639, 640, 743, 744, 760, 960, 1010, 1200, 1400 и 1920 px.

Служебные QA-скриншоты из `.codex-audit/` намеренно не публикуются в Git: они локальные и не нужны для продолжения разработки.
